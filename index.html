Grid map

When on, opening Add Grid Tally auto-fills the grid you were previously in (based on live GPS), and Subsequent Sighting auto-fills the grid you're currently in. Requires grid tracking (below) to be running. Off by default — always double-check before saving.
Alerts you when live grid tracking confirms you've moved into a new grid — useful without needing to look at the screen. Vibrate needs a recent tap on the screen to work at all (a browser restriction, not something this app controls) — Notify doesn't have that limitation, so it's the more reliable option if you're not actively touching the screen while walking. Requires grid tracking to be running either way.
Replaces the "+ Add Grid Tally" button with a persistent tally panel at the top of the page. Each tally saves immediately as you tap it — nothing is held back and lost if the app closes. Index nest thresholds (and predations) are checked immediately too, so a capture prompt can appear right on the tap that triggers it. The grid number tracks live GPS position; a manual correction sticks for a while (see below) before returning to live tracking. Requires grid tracking to be running.
Makes the tally steppers, labels, and grid number field bigger on the Add Grid Tally form. Only takes effect on a large tablet screen — never shrinks or crowds things on a phone.
Occasionally a sea turtle swims across the screen when you tap things. Purely decorative.

Master species totals

Syncs Loggerhead/Green/Leatherback/Kemp's running counts directly with the OneDrive master file, via two Power Automate flows — one reads, one writes. Staff editing that file directly (paper data entry) are automatically reflected the next time this app reads, since there's only one copy of the data, not a separate synced copy. Only Export writes to the master — Sync Now and the tappable sync indicator at the top only ever read. Clearing the day never syncs at all. This only ever warns if the connection is stale or unreachable — it never blocks tallying.
